# Aryan App

A mobile-friendly AI-style study chat interface for students, with English, Hindi, and Marathi language options. Get step-by-step Maths explanations, CET/JEE study planning, and quick practice prompts.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Features

- Responsive dark interface with purple and blue accents
- Chat screen with message composer, send button, and new chat controls
- English, Hindi, and Marathi interface and sample study responses
- Student-focused Maths explanations, exam planning, and practice quizzes
- Recent conversations saved in browser local storage
- Keyboard shortcuts: Enter to send, Shift+Enter for a new line, and Cmd/Ctrl+K for a new chat

## Note

This is a front-end demo. Replies are generated from built-in sample responses; connect a trusted AI service to enable live model responses. Do not put secret API keys in browser code.
